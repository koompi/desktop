# The KOOMPI manual

Start with [Coming from Mac or Windows](01-coming-from-mac-or-windows.md).
It is written for the first hour on a new machine and assumes you have used a computer before, just not this one.

After that, read whichever chapter answers the question in front of you.
None of them depend on the ones before.

Two things this manual cannot beat:

`Super+/` lists every shortcut on the machine, generated from the shortcuts themselves.
`Super+Shift+/` runs the tour, which opens each part of the desktop as it names it.

If this manual and either of those disagree, they are right.

The specification the desktop is built to is [`docs/navigation.md`](../navigation.md).
That one is for the people building KOOMPI, not for the people using it.
