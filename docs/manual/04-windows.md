# Windows

Windows share the screen instead of covering each other.
The first one takes everything.
The second splits it.
The third splits again, and so on.

This is the part that feels strangest coming from another desktop, and the part you stop noticing after a day.

## Moving your attention

`Super+Left`, `Super+Right`, `Super+Up` and `Super+Down` move the focus in that direction.
There is no cycling and no guessing which window comes next: you point at where it is on the screen.

## Rearranging

`Super+Shift+Left`, `Super+Shift+Right`, `Super+Shift+Up` and `Super+Shift+Down` move the window itself, swapping it with whatever was there.

`Super+;` and `Super+'` change how the split is divided.
Hold either one down to keep going.

To do it with the mouse, hold Super and drag the window anywhere.
Drag it towards an edge of the screen and an outline shows where it will land before you let go: a side gives you a half, a corner a quarter, the top edge the whole screen.

Hold Super and drag with the right button to resize.

## Size

| Keys | Does |
| --- | --- |
| `Super+D` | fill the screen, keeping the top strip |
| `Super+F` | true full screen, strip and all |
| `Super+P` | pin the window in front of everything, on every desk |
| `Super+Alt+Space` | let this one window float free of the split |
| `Super+Shift+Space` | float every window, and put them back again |

`Super+Shift+Space` is the escape hatch.
If tiling is not what you want today, that key gives you an ordinary overlapping desktop until you press it again.

## Closing

`Super+Q` closes the window.

`Super+Shift+Alt+Q` kills it, for the case where the program has stopped answering.
That loses whatever was unsaved, so it is the second thing you try, not the first.

`Alt+F4` is deliberately not a close key.
Press it and the desktop says which key to use instead.
It is left working inside a Windows virtual machine, where the program on the other side still expects it.

## What a window can do, without a shortcut

Click the program's name at the top left of the screen.
Close, float, full screen, pin and move to another desk are all there, each one showing the key that does the same thing.
Click it again to put the menu away.

Just to the right of the name sit the program's own menus: File, Edit, View.
They live in the top strip rather than inside the window.
