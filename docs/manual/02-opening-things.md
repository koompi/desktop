# Opening things

## Search

Tap Super, let go, and start typing.

Search answers with programs, files, open windows, settings pages, sums and the web, ranked by what you typed.
Press Enter to take the first answer, or arrow down to another one.

That is the whole launcher.
If you learn nothing else in this manual, learn this.

## Narrowing what Search looks at

A single character at the front of your query tells Search where to look.

| Type this first | And Search gives you |
| --- | --- |
| `>` | programs only |
| `~` | files |
| `@` | windows you already have open |
| `#` | settings pages |
| `=` | the answer to a sum |
| `?` | a web search |
| `$` | a shell command to run |
| `;` | your clipboard history |
| `:` | emoji |
| `/` | the desktop's own actions |

Without a prefix everything answers at once, which is usually what you want.
The prefixes are for when it is not.

## Everything installed, on one page

Put four fingers on the touchpad and spread them apart.
Every program on the machine appears, laid out to be looked at rather than typed at.
Bring the four fingers back together to close it.

This one has no keyboard shortcut, and that is deliberate.
Search is the keyboard's launcher; this is the touchpad's.

## Keys for the programs you open all day

| Keys | Opens |
| --- | --- |
| `Super+Return` or `Super+T` | a terminal |
| `Super+E` | the file manager |
| `Super+W` | your browser |
| `Super+C` | your code editor |
| `Super+X` | a text editor |
| `Super+I` | KOOMPI Settings |
| `Ctrl+Shift+Escape` | the task manager |

Each of these opens whatever you actually have installed, in a fixed order of preference.
`Super+W` finds Chrome first, then Zen, then Firefox, and so on down the list, so the key keeps working on a machine that has none of them but the last.

## Panels that come and go

Three programs open as a panel over your work instead of as a window on a desk.
Press the key once to bring it down, again to send it away.

| Keys | Panel |
| --- | --- |
| `Super` with `` ` `` | a terminal |
| `Super+\` | the system monitor |
| `Super+Y` | Telegram |

## Two more that are worth the muscle memory

`Super+V` opens your clipboard history.
Everything you have copied is there.
Type to filter, Enter to put it back on the clipboard, then paste it where you want it.

`Super+.` opens emoji, and Enter copies the one you picked.
Both of these are Search wearing a different hat, so the same typing and the same Enter apply.
